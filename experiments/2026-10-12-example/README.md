# Example: a preregistered experiment folder

Illustration only — a toy experiment showing what the `/preregister` skill
leaves behind:

- `PREREGISTRATION.md` — the filled form, committed before the run. Note the
  one `NOT PREREGISTERED` item (the researcher declined to answer) and the
  appended deviation (frozen sections untouched).
- `config.json` — every hyperparameter the run used.
- The matching entry in `research-log/log.md` quotes the preregistered
  prediction into *Expected Outcome* and puts prediction and outcome side by
  side in *Actual Outcome*, using the pre-agreed conclusion sentence.
